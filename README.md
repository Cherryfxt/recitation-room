# 背诵练习室

独立的道法与历史背诵网页应用。

访问：https://cherryfxt.github.io/recitation-room/

## 使用

先选择学科与背诵方式，再逐题作答。支持顺序背诵、单课随机、全部随机，单格首字提示、答案核对与薄弱题复习。

范围：道法第一、二单元完整材料；历史前九课及相关论述练习。原材料示例与补充参考答案在页面内分别标注。

## 进度

进度保存在当前设备与浏览器内，不会自动跨设备同步。可从入口的“进度备份与内容说明”导出、导入。首次从本机版迁移时，请先在本机版导出，再在线上版导入。

本仓库独立部署，线上进度使用独立存储标识 `recitation-room-v1`。

## 部署

GitHub Pages：从 main 分支根目录发布。无构建依赖、无后台服务。

## 内容说明

学习材料用于个人学习；不对教材和第三方材料授予额外版权许可。没有上传原始 Word 文件、本机路径、浏览记录或个人练习进度。
